## 뉴스를 추가하는 절차

1. 원문에서 발표일·사건일·계약 당사자를 확인합니다.
2. 발표의 범위를 계획, 협약, 허가, 확정 계약, 금융 종결, 건설, 상업운전으로 표시합니다.
3. 기존 용량과 신규 증가분을 분리하고, 금액이 총사업비인지 금융인지 구분합니다.
4. 기존 자료보다 새로운 사실이면 해당 프로젝트와 출처 목록을 함께 수정합니다.
5. 이전 목표와 새 목표를 모두 변경 이력에 남깁니다. 미확인은 빈칸 또는 null로 유지합니다.

## 투자 판단 전 질문

“고객이 있다”는 말만으로 충분하지 않습니다. 구매 의무와 계약 단가를 알고 있는가, 공사비 초과는 누가 부담하는가, 목표일까지 연료가 공급되는가, 필요한 추가 자금을 얼마나 조달해야 하는가, 현재 주가가 가정하는 성공 수준은 무엇인가를 순서대로 물어야 합니다.

**확정 자료가 없으면 낙관적인 숫자로 빈칸을 채우지 않습니다.** 정보 부족 자체가 판단에 필요한 정보입니다.

## 용어 사전

| 용어 | 쉬운 뜻 | 읽을 때 주의점 |
|---|---|---|
| GW·MW | 발전 설비나 전력의 크기를 표시하는 단위. 1GW=1,000MW | 실제 일정 기간 생산한 전력량과 다름 |
| MWh | 1MW를 한 시간 사용·생산한 전력량 | 전력 판매단가와 연결되는 단위 |
| MWe·MWt | 각각 전기 출력과 열 출력 | 원자로의 열 출력 전부가 전기가 되지는 않음 |
| SMR | 소형모듈원전. 상대적으로 작은 원자로를 모듈화하는 접근 | 모든 SMR이 같은 기술·연료를 쓰지 않음 |
| 경수로 | 일반 물을 냉각재와 중성자 감속재로 사용하는 원자로 | 첨단 원자로 전체의 동의어가 아님 |
| HALEU | U-235 비중이 5% 초과·20% 미만인 고순도 저농축우라늄 | 원광이나 완성 연료와 구분 |
| PPA | 전력구매계약. 고객과 발전사가 구매 조건을 정하는 계약 | 단가·기간·물량·해지 조건이 중요 |
| MOU | 양해각서. 협력 방향을 정하는 문서 | 문구에 따라 구속력이 달라지며 확정 주문과 같지 않음 |
| FID | 최종 투자결정. 사업 자금을 투입하겠다는 결정 | 허가와 금융 종결을 자동 의미하지 않음 |
| EPC | 설계·조달·시공을 수행하는 계약 방식 | 가격 상승과 지연 책임의 배분을 봐야 함 |
| FOAK | 처음 건설하는 초도호기 | 반복 생산 이전의 초기 비용과 시행착오 |
| Uprate | 기존 원전의 허용·실제 출력을 높이는 증강 | 새 발전소를 짓는 것과 구분 |
| NRC | 미국 원자력규제위원회 | 설계 승인·건설허가·운영 단계 문서를 구분 |
| DOE | 미국 에너지부 | 지원사업 선정과 실제 자금 집행을 구분 |
| IRS | 미국 국세청 | 세제 발표와 사업별 적격성 확인은 별개 |
| 조건부 대출 | 정해진 조건을 충족해야 실행되는 대출 | 전액 집행 완료나 무상 보조금이 아님 |
| 현금흐름 | 실제 현금이 들어오고 나가는 흐름 | 회계상 이익과 다를 수 있음 |
| 지분 희석 | 새 주식 발행 등으로 기존 주주의 비중이 줄어드는 현상 | 회사 성장과 주당 가치 증가가 같지 않을 수 있음 |

정책·연료 용어의 적용 사례는 [정책 문서](01-policy-and-capital.md), 허가 단계의 실제 사례는 [프로젝트 문서](02-projects.md)를 참고하세요.
